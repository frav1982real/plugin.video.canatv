# CanàTV

Addon Kodi per la TV italiana. La scaletta è `resources/data/channels.json` (da `canali.json`): LCN, nome e gruppo non vengono sovrascritti. WorldLiveTV e Sky servono solo a risolvere gli stream.

## Installazione

1. Impostazioni → Sistema → Componenti aggiuntivi → origini sconosciute = ON
2. Installa da file zip `plugin.video.canatv-1.0.8.zip`
3. Apri CanàTV → *Configura / Aggiorna canali* (obbligatorio dopo l'aggiornamento)

Kodi 19 Matrix o successivo. Per Live TV e DRM installa dal repo ufficiale **PVR IPTV Simple Client** e **InputStream Adaptive**.

I canali Sky/NowTV pay si risolvono alla riproduzione (stessa fonte degli altri addon). Serve InputStream Adaptive.
