# CanàTV

Addon Kodi per la TV italiana.
## Installazione

1. Impostazioni → Sistema → Componenti aggiuntivi → origini sconosciute = ON
2. Installa da file zip `plugin.video.canatv-1.1.0~rc4.zip`
3. Apri CanàTV → *Configura / Aggiorna canali* (obbligatorio dopo l'aggiornamento)

Kodi 19 Matrix o successivo. Per Live TV installa dal repo ufficiale **PVR IPTV Simple Client** e **InputStream Adaptive**.
